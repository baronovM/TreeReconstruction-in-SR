# Вычислительный эксперимент: вынужденный осциллятор Ван дер Поля

## 1. Цель эксперимента

Исследуется устойчивость алгоритмов восстановления структуры суперпозиции к шуму в матрице
смежности. Берётся известная физическая модель и строится её матрица смежности M. Матрица
зашумляется, из зашумлённой матрицы восстанавливается дерево суперпозиции. Затем проверяется,
совпадает ли восстановленная модель с исходной. Шум вносится только в матрицу M; измерения
предполагаются точными.

## 2. Модель

Рассматривается вынужденный осциллятор Ван дер Поля

  ẍ = μ(1 − x²)ẋ − x + A sin(ωt).

Модель отображает наблюдаемые переменные (x, ẋ, t) в ẍ. Её суперпозиция имеет вид

  ẍ = add₃( mul( aff( sq(x) ), ẋ ), sin(t), x ).

Словарь примитивных функций:
- add₃ — линейная комбинация трёх аргументов;
- mul — произведение двух аргументов;
- aff(u) = a₀ + a₁u — аффинное преобразование;
- sq(u) = u² — квадрат;
- sin(u) = sin(ωu) — синус с параметром частоты.

Матрица M имеет размер 6 × 8. Строки — корень и пять функций, столбцы — пять функций и три переменные.
Каждая строка содержит столько единиц, какова арность соответствующей функции.

Параметры модели — независимые нормальные случайные величины:
μ ~ N(8.53, 0.5²), A ~ N(1.2, 0.1²), ω ~ N(0.63, 0.02²).
Средние значения соответствуют хаотическому режиму осциллятора (рис. `vdp_phase.png`).
Линейность параметров определяется символьно: параметр считается нелинейным, если он входит
в аргумент нелинейной функции. В этой модели μ и A входят линейно, ω — нелинейно.

Выборка строится численным интегрированием уравнения на отрезке t ∈ [0, 60] (1500 отсчётов).
Начальные условия выбираются случайно. Целевая переменная ẍ вычисляется точно.

## 3. Зашумление и восстановление

Зашумлённая матрица строится как в [Neychev et al., 2024]:
N = M + αU, где U ~ U(−1, 1) поэлементно. Затем N линейно нормируется на [0, 1].
Уровень шума α меняется от 0 до 1 (41 значение). Для каждой реализации U строится кривая
качества по всем α. Эксперимент повторяется 20 раз с новыми параметрами модели, в каждом
повторе берётся 20 реализаций шума.

Сравниваются три алгоритма восстановления:
- жадный обход в глубину (DFS);
- жадный обход в ширину (BFS);
- модифицированный алгоритм Прима с ограничениями на арность.

Рассматриваются два словаря:
1. **Точный словарь** — только пять функций модели.
2. **Расширенный словарь** — в него добавлены три лишние функции (aff, mul, sq), которых нет
   в истинной модели. Это приближает постановку к практической, где словарь избыточен.

## 4. Критерии качества восстановления

Восстановление считается успешным по одному из пяти критериев:
1. **Точное совпадение матриц** M̂ = M — критерий исходной статьи.
2. **Символьная эквивалентность.** Модель раскладывается в сумму Σ c_k φ_k(x; θ). Здесь c_k —
   линейные коэффициенты, θ — нелинейные параметры. Модели эквивалентны, если совпадают наборы
   базисных функций φ_k, то есть модели совпадают с точностью до значений линейных коэффициентов.
   Для исходной модели базис такой: {ẋ, x²ẋ, x, sin(ωt)}.
3. **Нулевое редакционное расстояние** между деревьями (tree edit distance, алгоритм
   Чжана–Шаши). Порядок аргументов не учитывается. Кроме доли успехов, приводится среднее расстояние.
4. **Аппроксимация данных после переподбора параметров.** Нормированная среднеквадратичная ошибка
   (RMSE / std ẍ) должна быть меньше 10⁻³. Сравниваются два способа оценивания параметров:
   - **двухэтапный:** линейные коэффициенты находятся МНК при фиксированных нелинейных
     параметрах, а нелинейные оптимизируются алгоритмом Левенберга–Марквардта
     (метод проекции переменных);
   - **одноэтапный:** алгоритм Левенберга–Марквардта сразу по всем параметрам модели.

   Начальное приближение — априорные средние параметров. Для нелинейных параметров используется
   мультистарт (см. разд. 6).

## 5. Результаты

Доля верно восстановленных структур (среднее по 400 реализациям шума) приведена
на рис. `vdp_accuracy_exact_dict.png` и `vdp_accuracy_extra_dict.png`.
При α ≤ 0.5 все алгоритмы восстанавливают структуру безошибочно. Это следует из нормировки:
после неё элементы, соответствующие рёбрам, остаются больше остальных.
При α > 0.5 качество резко падает.

**Точный словарь**, критерий точного совпадения:

| α     | 0.55 | 0.60 | 0.65 | 0.70 | 0.80 | 1.00 |
|-------|------|------|------|------|------|------|
| DFS   | 0.87 | 0.66 | 0.51 | 0.33 | 0.18 | 0.06 |
| BFS   | 0.87 | 0.66 | 0.50 | 0.33 | 0.17 | 0.05 |
| Прим  | 0.88 | 0.68 | 0.54 | 0.36 | 0.20 | 0.07 |

**Расширенный словарь**, точное совпадение / аппроксимация данных (двухэтапный подбор):

| α     | 0.55        | 0.60        | 0.65        | 0.70        | 0.80        |
|-------|-------------|-------------|-------------|-------------|-------------|
| DFS   | 0.81 / 0.82 | 0.50 / 0.53 | 0.30 / 0.34 | 0.19 / 0.23 | 0.06 / 0.09 |
| BFS   | 0.81 / 0.82 | 0.50 / 0.53 | 0.30 / 0.33 | 0.19 / 0.23 | 0.06 / 0.09 |
| Прим  | 0.83 / 0.84 | 0.53 / 0.55 | 0.33 / 0.37 | 0.21 / 0.25 | 0.07 / 0.09 |

Основные наблюдения:
1. Алгоритм Прима устойчиво лучше жадных обходов, на 1–3 процентных пункта во всём
   диапазоне шума. Это согласуется с выводами исходной статьи. Для дерева из пяти функций
   разница между алгоритмами невелика. DFS и BFS дают практически одинаковый результат.
2. Избыточный словарь снижает качество: при α = 0.6 доля точных восстановлений падает
   с 0.66–0.68 до 0.50–0.53.
3. С точным словарём все критерии практически совпадают: любая неверная структура даёт
   неэквивалентную модель. С расширенным словарём критерии упорядочены так:
   аппроксимация данных ≥ символьная эквивалентность ≥ точное совпадение = нулевое редакционное расстояние.
   Некоторые структуры отличаются от исходной, но описывают те же данные. Например, лишний узел
   aff(x) = b₀ + b₁x на месте листа x расширяет семейство моделей, но содержит исходную модель.
   Такие структуры критерий точного совпадения считает ошибкой, хотя с точки зрения
   регрессии они корректны.
4. Двухэтапный подбор параметров не хуже одноэтапного. На расширенном словаре он примерно на 1 п.п.
   чаще находит параметры, воспроизводящие данные.
5. Среднее редакционное расстояние растёт с уровнем шума монотонно и гладко. Поэтому оно
   информативнее бинарного критерия как мера близости восстановленной структуры к исходной.
6. Восстановленное дерево может иметь большее правдоподобие по зашумлённой матрице, чем
   истинное (рис. `vdp_tree.png`). В таких случаях ошибка вызвана не алгоритмом: при данном
   уровне шума истинная структура перестаёт быть наиболее вероятной.

## 6. Многоэкстремальность по нелинейному параметру

Даже при верной структуре оценка частоты ω из одного начального приближения ненадёжна.
Функционал ошибки как функция ω имеет много локальных минимумов с шагом около π/T ≈ 0.05–0.07,
где T — длина окна наблюдения. При T = 60 и истинном ω = 0.573, отстоящем от априорного
среднего на 2.9σ, оба метода сходились к посторонним минимумам: 0.648 и 0.702.
Это известное свойство задачи оценивания частоты гармонического сигнала. Для устранения
проблемы используется мультистарт: нелинейные параметры инициализируются значениями
m + kσ, k ∈ {−3, …, 3}, и выбирается лучшее решение. С мультистартом верная структура
аппроксимирует данные (ошибка порядка 10⁻¹⁵) во всех 20 повторах.

## 7. Ограничения и дальнейшая работа

- Алгоритмы на основе PCST (k-MST и его комбинации с DFS, BFS и алгоритмом Прима)
  в данном эксперименте пока не сравнивались.
- Дерево модели невелико (пять функций), поэтому различия между алгоритмами малы.
  Следующие модели — Лотки–Вольтерры и Лоренца, затем МГД-модель с векторными вершинами.

# Вычислительный эксперимент: модель Лотки–Вольтерры

## 1. Модель

Рассматривается модель «хищник–жертва»

  ẋ = x(α + βy),  ẏ = y(γ + δx),

где x — численность жертв, y — численность хищников. В этой записи знаки входят в параметры: β, γ < 0.
В отличие от осциллятора, модель — система из двух уравнений. Правые части зависят от общих
переменных (x, y), но структурно независимы. Поэтому задача восстановления системы распадается
на две независимые задачи: у каждого уравнения своя суперпозиция и своя матрица смежности.

  ẋ = mul( aff(y), x ),  ẏ = mul( aff(x), y ).

Словарь каждого уравнения состоит из двух функций: mul и aff(u) = a₀ + a₁u. Матрица M имеет
размер 3 × 4. Параметры — независимые нормальные случайные величины:
α ~ N(1.1, 0.1²), β ~ N(−0.4, 0.04²), γ ~ N(−0.4, 0.04²), δ ~ N(0.1, 0.01²).
Все четыре параметра входят в модель линейно: после раскрытия скобок получаются базисы {x, xy}
и {y, xy}. Поэтому переподбор параметров сводится к МНК, и мультистарт не требуется.
Выборка строится интегрированием системы на отрезке t ∈ [0, 60] (1500 отсчётов) из случайных начальных условий
x₀, y₀ ~ U(1, 10). Целевые переменные ẋ и ẏ вычисляются точно. Траектории — замкнутые
циклы (рис. `lv_phase.png`).

## 2. Постановка эксперимента

Зашумление, алгоритмы восстановления, словари и критерии те же, что для осциллятора (разд. 3–4).
Расширенный словарь получается добавлением тех же лишних функций aff, mul, sq к словарю каждого уравнения.
Шум вносится в матрицу каждого уравнения независимо. Качество оценивается отдельно по каждому уравнению
и для системы в целом. Система считается восстановленной, если в одной реализации шума верно
восстановлены оба уравнения. Редакционное расстояние для системы — сумма расстояний по уравнениям.
Число повторов, реализаций шума и значений α — как для осциллятора (20 × 20 × 41).

## 3. Результаты

Доля верно восстановленных систем (рис. `lv_accuracy_*_system.png`; по уравнениям — `*_dx.png`, `*_dy.png`):

| α                                      | 0.55 | 0.60 | 0.65 | 0.70 | 0.80 | 1.00 |
|----------------------------------------|------|------|------|------|------|------|
| точный словарь, точное совпадение      | 0.95 | 0.85 | 0.72 | 0.63 | 0.47 | 0.30 |
| расширенный словарь, точное совпадение | 0.88 | 0.67 | 0.48 | 0.32 | 0.16 | 0.04 |
| расширенный словарь, аппроксимация     | 0.90 | 0.71 | 0.54 | 0.39 | 0.22 | 0.07 |

Основные наблюдения:
1. Как и для осциллятора, при α ≤ 0.5 все алгоритмы восстанавливают структуру безошибочно.
2. DFS, BFS и алгоритм Прима дают одинаковый результат (различия не более 0.01). В дереве
   из двух функций у алгоритмов почти нет выбора: различаться может только порядок присоединения листьев.
3. Для одного уравнения падение качества с ростом шума медленнее, чем для осциллятора
   (при α = 0.7 точное совпадение 0.78–0.80 против 0.33–0.36): матрица меньше, и ошибиться в ней
   можно меньшим числом способов. Для системы доли успеха по уравнениям примерно перемножаются,
   поэтому качество восстановления системы близко к качеству восстановления осциллятора.
4. На расширенном словаре порядок критериев тот же: аппроксимация ≥ символьная эквивалентность ≥
   точное совпадение. Двухэтапный подбор (здесь это чистый МНК) и LM дают практически
   одинаковый результат, так как задача линейна по параметрам.
